# Games

Browser games, hosted with GitHub Pages. No build step: each game is a self-contained `index.html`.

- [`holdem-trainer/`](holdem-trainer/): Home Game Hold'em Trainer. Practice Texas Hold'em against opponents tuned like a passive, limp-heavy home game (10¢/20¢ blinds, $20 buy-in). A coach grades each decision, explains why, and suggests bet sizes. Stats are saved in your browser.
