# Games

Browser games, hosted with GitHub Pages. No build step: each game is a self-contained `index.html`.

- [`holdem-trainer/`](holdem-trainer/): Home Game Hold'em Trainer. Practice Texas Hold'em against opponents tuned like a passive, limp-heavy home game (10¢/20¢ blinds, $20 buy-in). A coach grades each decision, explains why, and suggests bet sizes. Practice tools, each with an on/off setting: drills that deal straight to one kind of spot (or your weakest one), a redo list that brings back spots you missed until you get them right twice in a row, and stats broken down by situation. Opponents' styles are hidden by default; read them from the play/raise numbers under each name. Stats are saved in your browser.
